Incidental Task (IT) Taxonomy Reference

IT Code Task Definition
IT-1 Select an account or identity when authentication becomes necessary
IT-2 Decide whether to supply saved credentials or enter credentials manually
IT-4 Supply personal information or autofill address and contact forms
IT-5 Resolve a request for browser permissions (location, notifications)
IT-6 Resolve cookie and tracking-consent choices
IT-7 Decide whether task data may be reused for secondary purposes (AI model training opt-in/opt-out)
IT-8 Decide and authorize an application connection (Google Drive)
IT-9 Respond to website warnings or alerts (2-minute session expiry notice)
IT-10 Decide whether to retain / save details for future purchases (save card)
IT-11 Decide whether to receive news, updates, or promotional materials (newsletter subscription, SMS flight notifications)
IT-12 Fill additional options (warranty plan upsell, promotional coupon codes)
IT-13 Fill optional details (delivery instructions, gate access PIN, weekend delivery)
IT-14 Resolve whether to disclose to recipient (External Recipient Warning)
IT-15 Resolve recipient content visibility and permission scope (Viewer, Commenter, Editor)
IT-16 Set time limit while sharing sensitive information (Access expiration duration)
IT-17 Reveal sensitive obscured information (CVV security code)
IT-18 Handle virtual communication & recording consent (Meeting recording, live transcription disclosure)
IT-19 Choose MFA strategy (simulate Wallet PIN, passkey, or OTP verification)
IT-21 Configure workspace or environment preferences
IT-22 Decide to use internal tools or extensions (inline typo spell check & auto-correct)
